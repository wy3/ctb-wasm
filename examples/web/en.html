CTB-WASM

GeoTIFF → Cesium Terrain ZIP

Read an elevation GeoTIFF in your browser, generate quantized-mesh tiles and layer.json, then download them as a ZIP archive.

Download generated ZIP

Choose a GeoTIFF to get started.

Input requirements

  • Single-band, EPSG:4326, north-up, unrotated, PixelIsArea.
  • Elevations must be in meters. Sampling a NoData value fails.
  • Samples outside the raster bounds use the nearest edge value.
  • High zoom levels or large files use substantial memory; start low.
